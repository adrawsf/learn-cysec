# What I learned

HTTP is stateless. Everything revolves around Requests and Responses.

## Key Concepts

- **Methods**: GET, POST, PUT, DELETE, OPTIONS, HEAD.
- **Headers**: Host, User-Agent, Cookie, Authorization.
- **Status Codes**: 
  - 200 (OK)
  - 302 (Found/Redirect)
  - 401 (Unauthorized)
  - 403 (Forbidden)
  - 500 (Internal Server Error)
