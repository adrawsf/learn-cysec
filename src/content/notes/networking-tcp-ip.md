# What I learned

The TCP/IP model is a more concise version of the OSI model, focusing on practical implementation.

## Key Concepts

- **Link Layer**: Equivalent to OSI Physical and Data Link.
- **Internet Layer**: IP addressing and routing.
- **Transport Layer**: TCP (reliable) vs UDP (unreliable, fast).
- **Application Layer**: Combines OSI Session, Presentation, and Application.

## Commands / Examples

```bash
# Check routing table
netstat -rn
# Trace route to host
traceroute example.com
```
