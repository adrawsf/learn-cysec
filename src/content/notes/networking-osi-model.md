# What I learned

The Open Systems Interconnection (OSI) model describes seven layers that computer systems use to communicate over a network.

## Key Concepts

1. **Physical Layer**: Cables, switches, the physical connection.
2. **Data Link Layer**: MAC addresses, frames, switches.
3. **Network Layer**: IP addresses, routers, packets.
4. **Transport Layer**: TCP/UDP, ports, segments.
5. **Session Layer**: Establishing, managing, and terminating sessions.
6. **Presentation Layer**: Data formatting, encryption, compression.
7. **Application Layer**: HTTP, FTP, user-facing protocols.
